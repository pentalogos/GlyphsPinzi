# Glyphs IDS Composer

专为 Glyphs 编写的汉字自动拼字脚本。基于 Ideographic Description Sequences (IDS) 规则，自动检索当前字体中已有部件，并将其组合生成新的汉字字符型。

## 特性

- **自动生成**：根据 IDS 拆解规则，自动检索并生成字体中已有部件可拼成的新字。
- **字表范围控制**：支持根据指定字表筛选生成的字符，避免产生过多生僻字。
- **召唤同族字**：一键召集与当前字符共享部件的“同族”字，极大地提高手动拼字效率。
- **最优路径规划**：通过贪心算法计算拼完整个字表所需制作的最少“种子字”集合。

## 安装与运行

### 运行环境要求

在使用前，请确保您的 Glyphs.app 已安装必要的运行环境：

1. 打开 Glyphs 顶部菜单栏 -> **窗口** -> **插件管理器**。
2. 切换至 **模块** 标签页，确认已安装 **python** 和 **Vanilla**。
3. 如果是首次安装，请根据提示重启 Glyphs。

### 安装步骤

1. 下载 [Releases](https://github.com/pentalogos/GlyphsPinzi/releases) 页面中的 `IDS_Composer.py` 和 `IDS_Summoner.py`。
2. 点击 Glyphs 顶部菜单栏中的 **脚本 (Script)** -> **打开脚本文件夹 (Open Scripts Folder)**。
3. 将上述脚本放入该目录中。
4. 重新打开 Glyphs，在“脚本”菜单中即可看到并运行。

## 核心功能：IDS 汉字拼字 (`IDS_Composer.py`)

这是本项目的主功能，用于自动分析当前字体中已有的部件，并一键生成所有可以拼合出的新汉字。

### 使用方法

1. **运行脚本**：点击 Glyphs 菜单 -> 脚本 -> IDS 汉字拼字。
2. **选择字表**：在弹出的窗口中选择目标字表（如《通用规范汉字表》）。若不选择，则默认检索 IDS 数据库支持的所有字符。
3. **自动分析**：脚本会扫描字体中已有的 Unicode 字符，并计算利用这些字符作为部件能“解锁”哪些新字。
4. **预览与确认**：
   - 脚本会在宏窗口（Macro Window）输出检索报告。
   - 弹出对话框提示找到的新字数量，确认后即可开始创建。
5. **结果**：
   - 自动在字体中创建新字符型（Glyph）。
   - 自动填充 Unicode 编码、设置 UPM 全角宽度。
   - 在字符的 Note 字段标注其 IDS 拆解关系。

## 辅助功能：召唤同族字 (`IDS_Summoner.py`)

在编辑某个汉字时，快速召集字体中所有与之共享部件的“同族”字符，方便直接取用已有字的部件。

### 使用方法

1. 在 Glyphs 中双击进入某个汉字的编辑界面。
2. 运行脚本：点击 Glyphs 菜单 -> 脚本 -> 召唤同族字。
3. 在弹出窗口中选择模式，点击“召唤同族字”按钮。

### 两种检索模式

- **宽松模式**（默认）：只要共享任一叶子部件即视为同族。
- **严格模式**：部件须在 IDS 结构中出现在**相同位置**才视为同族。例如“明”（⿰日月）严格匹配“晴”（⿰日青），但不匹配“早”（⿱日十）。

### 选项

- **在当前标签页打开**：默认勾选。同族字将追加到当前编辑标签页，并自动过滤掉已经在标签页中打开的字符以避免重复。取消勾选则在新标签页中整体打开。

> **注意**：此脚本依赖 `IDS_Composer.py` 的内嵌数据，请确保两个脚本放在同一目录下。

## 进阶：拼字规划工具 (`calc_minimal_charsets.py`)

为了帮助字库开发者制定最高效的制作计划。该脚本通过**贪心算法**，计算出拼完一个字表所需制作的最少字符集合。

### 逻辑模式

1. **完备模式**：要求部件必须同结构位置才能用于拼合。适合追求部件形态多样的字库。
2. **基本模式**：部件出现即可用。适合字形规整、追求最高拼合率的字库。

### 使用方法

1. 将目标字表放入 `字表/` 目录。
2. 运行脚本：`python3 calc_minimal_charsets.py`
3. 结果将按模式分类生成在 `拼字表/` 文件夹下。

## 更新 IDS 数据库或字表

如果需要更新 `ids.txt` 或自定义字表范围：

1. 确保环境中有 Python 3。
2. 更新根目录下的 `ids-20240112.txt` 或 `字表/` 目录。
3. 运行更新脚本：`python3 build_embedded_data.py`
4. 脚本会自动将数据压缩并注入到 `IDS_Composer.py` 源码中。注入后替换旧脚本即可。
