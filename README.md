# Glyphs IDS Composer

专为 Glyphs 编写的汉字自动拼字脚本。基于 Ideographic Description Sequences (IDS) 规则，自动检索当前字体中已有部件，并将其组合生成新的汉字字符型。

## 特性

- **自动生成**：列出字体已有字符，根据 IDS 拆解规则，自动生成能拼装出的新字。
- **字表范围控制**：支持根据指定的字表（如 GB2312、Big5、通用规范汉字表等）筛选生成的字符，防止产生过多的无用生僻字。
- **最优路径规划**：新增辅助脚本，通过贪心算法计算在不同策略下拼完整个字表所需的最少手工制作字数。

## 安装与运行

### 运行环境要求

在使用前，请确保您的 Glyphs.app 已安装必要的运行环境：

1. 打开 Glyphs 顶部菜单栏 -> **窗口** -> **插件管理器**。
2. 切换至 **模块** 标签页，确认已安装 **python** 和 **Vanilla**。
3. 如果是首次安装，请根据提示重启 Glyphs。

### 安装步骤

1. 下载 [Releases](https://github.com/pentalogos/GlyphsPinzi/releases) 页面中的 `IDS_Composer.py`。
2. 点击 Glyphs 顶部菜单栏中的 **脚本** -> **打开脚本文件夹**。
3. 将 `IDS_Composer.py` 放入该目录中。
4. 重新打开 Glyphs，点击“脚本”菜单，选择“IDS 汉字拼字”即可运行。

## 拼字规划工具 (`calc_minimal_charsets.py`)

为了帮助字库开发者制定最高效的制作计划，项目新增了 `calc_minimal_charsets.py` 脚本。该脚本基于**贪心算法**，能够计算出拼完一个完整字表所需制作的最少字符集合（即“种子字”），并支持两种逻辑模式：

### 1. 完备模式 (完备拼字表)
- **核心逻辑**：“部件-位置”即单位。
- **特点**：只有当部件作为一个**独立字符**存在时，才能用于拼合其他字。
- **示例**：有了“陪”（⿰阝咅）并不能拼出“部”（⿰咅阝），因为“阝”在左和“阝”在右被视为不同形态。
- **适用场景**：字形富于变化，且追求每个部件都有独立的母版进行微调时。

### 2. 基本模式 (基本拼字表)
- **核心逻辑**：部件出现即可用。
- **特点**：制作一个字后，其所有层级的 IDS 子部件都自动变为可用。
- **示例**：有了“陪”后，“阝”和“咅”都标记为可用，进而可以拼出“部”。
- **适用场景**：字形规整，快速扩充字库，追求最高拼合率时。

### 使用方法
1. 将字表放入 `字表/` 目录。
2. 运行脚本：
   ```bash
   python3 calc_minimal_charsets.py
   ```
3. 结果将生成在 `拼字表/` 文件夹下，按模式分类存储。

实际上来看，其计算结果仍有冗余，其原因是 IDS 分级不够细，且目标是字而不是部件，但这对富有变化的手写字体来说又是好事。

## 更新 IDS 数据库或字表

脚本内置了运行所需的数据集。如果需要更新 `ids.txt` 或新增自定义范围字表：

1. 确保您的环境中有 Python 3。
2. 将新的 `ids.txt` 文件放入本仓库根目录。
3. 若需新增字表，请将每行只有一个标准字符形名称（如 `uni554A` 或 `u2B6AD`）的纯文本文件放入 `字表/` 目录中。
4. 运行更新脚本：
   ```bash
   python3 build_embedded_data.py
   ```
5. 该脚本会自动对数据进行 `zlib` 和 `base64` 压缩处理，并将新的数据体无缝注入到 `IDS_Composer.py` 的底部。注入成功后，替换旧的脚本即可使用最新数据。
